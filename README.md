# NDVI Crop Calendar Dashboard

เว็บดูกราฟ NDVI และปฏิทินพืช (วันปลูก/เก็บเกี่ยว) ของไทย กัมพูชา ลาว และอินเดีย

เว็บ: https://gisfitt.github.io/ndvi_dashboard/

## โครงสร้าง repo

| ที่อยู่ | มีอะไร | หมายเหตุ |
|---|---|---|
| branch `main` | โค้ดเท่านั้น (`index.html`, `.gitignore`, สคริปต์) | ไม่เก็บข้อมูล JSON |
| branch `gh-pages` | เว็บ + ข้อมูล JSON ทั้งหมด | ถูกสร้างใหม่ทุกครั้งที่ deploy (ประวัติไม่สะสม) |

ข้อมูลอยู่ในโฟลเดอร์ `thailand/`, `cambodia/`, `laos/`, `india/` ซึ่งถูกระบุใน `.gitignore` จึงไม่เข้า `main`

แต่ละประเทศมีไฟล์:
- `raw_index.json` ดัชนีว่า ID ไหนอยู่ไฟล์จังหวัดไหน
- `raw/<จังหวัด>.json` ข้อมูล NDVI แยกตามจังหวัด
- `est_ndvi.json` วันปลูก/เก็บเกี่ยวที่ประมาณได้ของแต่ละแปลง

## อัปเดตข้อมูลรายสัปดาห์

1. รัน `readcsv_json_test_v3_GIT.py` สคริปต์จะเขียนไฟล์ JSON ลง `D:\GIT_HUB\ndvi_dashboard` (ลบไฟล์ `raw/*.json` เก่าก่อนเขียนใหม่)
2. รัน `python deploy_gh_pages.py` แล้วพิมพ์ `yes` เมื่อถาม
3. รอประมาณ 1–2 นาที แล้วเปิดเว็บ กด Ctrl+F5 ถ้ายังเห็นข้อมูลเก่า

ไม่ต้อง commit ข้อมูลใน GitHub Desktop

## แก้ตัวเว็บ (`index.html`)

1. แก้ไฟล์ แล้วทดสอบในเครื่อง
2. commit และ push เข้า `main` ตามปกติ
3. รัน `python deploy_gh_pages.py` เพื่อขึ้นเว็บ

## ตั้งค่าครั้งแรก (ทำแล้ว)

- Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`
- `.gitignore` มี `thailand/`, `cambodia/`, `laos/`, `india/`, `__pycache__/`
- `deploy_gh_pages.py` ตั้งค่า `SOURCE`, `REPO`, `HTML` ไว้บรรทัดบนสุดของไฟล์

## ข้อควรระวัง

- `deploy_gh_pages.py` ใช้ `git push --force` กับ branch `gh-pages` เท่านั้น ข้อมูลเก่าบน `gh-pages` จะถูกแทนที่ทั้งหมด ต้นฉบับข้อมูลอยู่ใน CSV ของ OneDrive และสร้างใหม่ได้จากสคริปต์
- อย่าเอาโฟลเดอร์ประเทศออกจาก `.gitignore` ไม่เช่นนั้นข้อมูลจะเข้า `main` และ repo จะโตขึ้นทุกสัปดาห์
- สคริปต์ deploy ต้องการ Git ที่ติดตั้งในเครื่องและล็อกอิน GitHub ไว้แล้ว
- ก่อน deploy ตรวจว่าทั้ง 4 ประเทศมี `raw_index.json` มิฉะนั้นสคริปต์จะหยุดพร้อมข้อความแจ้ง
- ข้อมูลกัมพูชา: `est_ndvi.json` มีแปลงมากกว่าที่มีข้อมูล NDVI ใน raw (ตรวจเมื่อ 2026-11-19) แปลงที่ไม่มี raw จะไม่มีเส้น NDVI

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| เว็บเปิดแต่ไม่มีข้อมูล | ยังไม่ได้ deploy หรือ Pages ยังชี้ผิด branch | ตรวจว่า branch `gh-pages` มีโฟลเดอร์ประเทศ และตั้ง Pages ถูก |
| เห็นข้อมูลเก่า | แคชของเบราว์เซอร์ | กด Ctrl+F5 |
| `Missing ... raw_index.json` | ยังไม่ได้รันสคริปต์สร้างข้อมูล | รัน `readcsv_json_test_v3_GIT.py` ก่อน |
| `git push failed` | ยังไม่ได้ล็อกอิน GitHub หรือไม่มีสิทธิ์ | ลอง `git push` ธรรมดาหนึ่งครั้งเพื่อล็อกอิน |
| `python` ไม่รู้จัก | ไม่ได้ตั้ง PATH | ใช้ `py deploy_gh_pages.py` |
| จังหวัดหายไปหลังอัปเดต | ไม่มีแปลงในจังหวัดนั้นในรอบนี้ | ปกติ ไฟล์ของจังหวัดนั้นถูกลบและไม่อยู่ในดัชนี |
